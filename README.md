# Code Alpha Internship — Books Data Analysis (Task 2)

## What this project does
This folder contains an end-to-end EDA (Exploratory Data Analysis) workflow for the Books dataset and exports Power BI-ready CSVs.

### Key outputs
After running the analysis you will get:
- **8 visualizations (PNG, 300 DPI)**
  - `01_price_distribution.png`
  - `02_rating_distribution.png`
  - `03_price_by_category.png`
  - `04_rating_by_category.png`
  - `05_price_vs_rating.png`
  - `06_availability_status.png`
  - `07_category_distribution.png`
  - `08_heatmap_rating_analysis.png`
- **Power BI ready CSV exports** (generated by the Python script)
  - `powerbi_category_summary.csv`
  - `powerbi_rating_summary.csv`
  - `powerbi_availability_summary.csv`
  - `powerbi_kpi_summary.csv`

## Files in this folder
- `code_alpha_analysis.py` — main analysis script (loads CSV, prints insights, generates PNGs, exports Power BI CSVs)
- `run_analysis.bat` — one-click launcher
- `requirements.txt` — Python dependencies
- `powerbi_books_detailed.csv` — input dataset

## How to run
### Option A — One click (Windows)
1. Double-click **`run_analysis.bat`**

### Option B — Run manually
From this folder:
```bat
py code_alpha_analysis.py
```

## Notes
- `run_analysis.bat` skips the Power BI setup step because `powerbi_setup.py` is not present in this folder.
- If your system doesn’t have Python available as `python`, use the `py` launcher.
